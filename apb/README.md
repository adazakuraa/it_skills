# AP科目B 過去問ノート

応用情報技術者試験 科目B（午後）の過去問を、分野ごとに「要約 → 問題 → 解答」の順で学ぶスマホ向けアプリです。
GitHub Pages では `.../apb/` で開けます（ビルド不要の静的サイト）。

- 収録：平成28年度秋期〜令和7年度秋期の秋期試験（令和2年度は10月試験）全110問
- 問題文：IPA公開の問題冊子PDFをページ画像化（令和4年度・令和7年度はPDFが10MB超のため未収録。令和7年度はテキスト版を表示）
- 要約・考え方：本アプリ独自の学習メモ。解答はIPA公表の解答例に基づく
- 出典：独立行政法人情報処理推進機構（IPA）応用情報技術者試験 午後問題・解答例

## データの作り方

```
python3 -I apb/tools/build.py <PDFのフォルダ> <作業用テキスト出力先>   # 問ごとに分割・OCR・ページ画像化
python3 -I apb/tools/aims.py <作業用テキスト出力先>                   # 解答例PDFから「出題趣旨」を抽出
# data/q/<回>-q<NN>.json に要約・解答・考え方を書く
python3 -I apb/tools/pack.py                                         # ページ画像を問ごとに連結、解説をbundle.jsonへ
python3 -I apb/tools/catalog.py                                      # 一覧用 catalog.json を生成
```

PDFのファイル名はIPAの元の名前（例 `2023r05a_ap_pm_qs.pdf`）のままにしてください。
