# EasyBand prototype

スマホ・タブレットのブラウザで、楽器を簡単に鳴らすためのWebアプリ試作です。

## 起動

`index.html` をWebサーバーから配信して開いてください。スマホのブラウザでは、ローカルファイル直開きよりHTTPS配信を推奨します。

## 現在のプロトタイプ

- ピアノ：鍵盤
- アコースティックギター／エレキギター／ベース：弦UI、タップ、簡易スワイプ
- ヴァイオリン／チェロ／木管／金管：音域パッド
- カホン：4ゾーン専用UI
- マルチタッチ
- Pointer Eventsによる高速連打・同時タッチ
- 対応端末では `PointerEvent.pressure` を音量に利用
- 非対応端末では安全な既定値
- Web Audio APIによるリアルタイム合成

## 重要

この版は「動作するUI/音響エンジンの試作」であり、13楽器のリアルな実録音音源を同梱してはいません。Webアプリで実際の楽器音に近づけるには、次段階でライセンス上利用可能なサンプル音源／SoundFont／サンプルライブラリを組み込み、各楽器についてマルチサンプル＋ベロシティレイヤー＋エンベロープ＋必要なアーティキュレーションを実装します。

本プロトタイプでは、短い連打で前の音を無理に停止せず、各Pointer IDを独立に扱うため、同じ場所の高速連打や同時タッチを想定しています。
