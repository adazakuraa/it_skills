# 実際のLinuxとの差異（シミュレーターの制約）

CyberLab のターミナルは教育用の独自実装です。安全性のため実OSには一切触れず、
JavaScriptのデータ構造だけを操作します。そのため本物のLinuxと以下の点で異なります。
学習者が「どこまでが本物と同じか」を正しく理解できるよう、差異を明記します。

## シェル
- **コマンド置換 `$(...)` / バッククォート、プロセス置換は未対応**（安全性のため意図的に実行しません）。
- **制御構文（if/for/while/case）は未対応**。シェルスクリプトは1行ずつ逐次解釈し、制御構文の行はスキップして警告します。
- バックグラウンド実行 `&`、ジョブ制御、サブシェル `(...)`、ヒアドキュメントは未対応。
- 変数展開は `$VAR` `${VAR}` `$?` `$#` `$@` `$1..$9` に限定。算術展開 `$((...))` は未対応。
- グロブは `* ? [...]` に対応。`{a,b}` 展開や `**` は未対応。

## コマンド
- 各コマンドは代表的なオプションのみ実装。未対応オプションはエラーまたは無視します。
- `sed` は `s///`、行削除 `Nd` `/re/d`、`Np` など一部スクリプトのみ対応。
- `awk` は `{print $N}`、`NR==N`、`/re/{...}` など代表的な用法のみ対応。
- `md5sum` / `sha256sum` は**暗号学的に正しいハッシュではありません**（固定長の擬似ハッシュ）。ハッシュの「概念」を学ぶ用途に限ります。
- `ping` `nmap` `curl` などネットワーク系は Phase 3 以降で仮想ネットワークに対して実装予定。現時点では未実装です。
- `tail -f` の追従、`top` のリアルタイム更新、`vi`/`nano` の対話編集は再現しません。

## ファイルシステム
- シンボリックリンク／ハードリンクは簡略化（`ln` は `cp` 相当）。
- inode・デバイスファイル・マウントは再現しません（`/dev/null` のみ特殊対応）。
- タイムスタンプは atime/ctime を持たず mtime のみ。

## 権限・ユーザー
- パスワード認証は省略（`sudo` はミッション設定で許可されていれば無条件に通ります）。
- ケイパビリティ、ACL、SELinux/AppArmor は未対応。
- SUID/SGID はビットの表示・検索・判定は再現しますが、実際の特権昇格は起こりません（学習用の見立て）。

## 安全性に関する設計
- `eval` / `new Function` / 文字列 `setTimeout` を一切使用しません。
- ユーザー入力は独自パーサーで解釈し、ホストのJavaScriptやOSには決して渡しません。
- 画面出力・保存データはすべて `textContent` で描画し、XSSを防ぎます。
- 外部ネットワーク通信は行いません（コンテンツはすべて同梱のJSモジュール）。

これらの差異は学習を妨げないよう設計していますが、**実機での挙動を確認する習慣**も大切にしてください。
本シミュレーターで考え方を身につけ、TryHackMe等の実環境で裏付ける——という使い方を想定しています。
